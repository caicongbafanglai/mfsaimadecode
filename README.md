# Microhard Flight Simulator

  Microhard Flight Simulator 是一个基于 Three.js/WebGL 的浏览器 3D 飞行模拟器。项目以 A320neo
  风格客机为主角，包含开放世界地形、机场、城市、昼夜循环、HUD、推力档位、飞行动力学、多人状态同步和本地离线降级能力。

  ## 功能概览

  - **A320neo 风格飞机**：包含真实比例参考的机身、机翼、发动机、起落架、襟翼、缝翼、扰流板、方向舵、升降舵、导航灯和着陆灯。
  - **飞行动力学**：60 Hz 固定步进模拟升力、阻力、推力、重力、地面滑跑、起飞、降落、失速训练、低能量、超速和迎角保护。
  - **推力系统**：支持 `IDLE`、`CL`、`FLX/MCT`、`TOGA`、`REV IDLE`、`MAX REV` 档位，包含左右推力杆、反推、A/THR、Managed/Selected 速度、Alpha Floor 和 TOGA
  Lock。
  - **开放世界**：约 52 km x 52 km 地图，包含大陆、岛屿、隐藏岛、山地、海岸、湖泊、河流、桥梁、公路、森林、农田、村庄、城市、车辆、船只、鸟群和云层。
  - **机场系统**：内置 18 个机场/跑道点位，包含国际机场、区域机场、本地机场、挑战进近机场和隐藏远程跑道。
  - **驾驶舱/HUD**：显示速度、高度、N1、航向、FMA、推力杆状态、V/S、VFE、VLS、襟翼、扰流板、最近机场、姿态仪、模拟时间和可缩放导航图。
  - **音频反馈**：使用 Web Audio API 合成发动机声、风噪、跑道滚动、轮胎、刹车、反推、TOGA 推力、驾驶舱震动和警告提示音。
  - **多人同步**：Node HTTP 服务提供会话、状态同步、世界快照和离开接口；客户端插值显示远程飞机和航迹。
  - **动态画质**：内置 `SMOOTH_LOW_POWER`、`BALANCED`、`HIGH`、`ULTRA`、`EMERGENCY_LOW` 预设，支持运行时诊断面板、帧时间监控和自动降级。
  - **世界事件**：包含服务器调度的 UFO/隐藏岛探索彩蛋。

  ## 技术栈

  - Three.js ES module
  - 原生 JavaScript ES modules
  - WebGL2
  - Web Audio API
  - Node.js HTTP server
  - 无前端框架、无打包器依赖

  ## 快速开始

  需要安装 Node.js，并使用支持 WebGL2 的现代浏览器。

  ```bash
  node server.js

  打开：

  http://localhost:4175/

  也可以指定端口：

  PORT=3000 node server.js
  # 或
  node server.js 3000

  server.js 会同时提供静态文件和多人/世界 API。只用普通静态服务器也可以启动单机渲染，但多人同步、服务器时间和服务端世界事件会不可用，客户端会自动进入本地模式。

  ## 构建与检查

  npm run build

  该命令会：

  1. 将 src/**/part-*/source.js 和 source.css 拼接成对应的生成文件。
  2. 对服务端、主入口、多人模块、UFO 模块和 HUD 模块执行语法检查。

  注意：带有 Generated by tools/buildVirtualSources.js 头部的文件是生成文件。开发时优先修改对应目录下的 part-*/source.js 或 source.css。

  ## 服务端 API

  本地服务器提供以下接口：

  - POST /api/session：创建玩家会话并返回呼号、飞机编号、服务器时间和玩家列表。
  - POST /api/state：上传本机飞机状态并返回世界快照。
  - GET /api/world：读取世界快照、服务器时间和世界事件。
  - POST /api/leave：离开会话。
  - GET /world：读取世界配置摘要。

  ## 部署建议

  - 使用 node server.js 或等价的 Node 进程托管项目根目录。
  - 需要反向代理时，将 /api/session、/api/state、/api/world、/api/leave 和静态资源一起转发到同一个服务。
  - 浏览器必须能加载 ES modules、WebGL2 和 Web Audio API。
  - 若部署到子路径，可在 index.html 的 window.MICROHARD_CONFIG 中调整 BASE_PATH、API_BASE_URL 和资源路径。
